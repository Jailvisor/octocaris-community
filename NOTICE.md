# Notice and attribution

This repository is a catalog for the [Octocaris](https://github.com/Jailvisor/octocaris)
wallpaper engine. It stores the index, preview images and thumbnails; the wallpaper
archives are attached to the repository's GitHub release.

All items originate from the **Steam Workshop** (Wallpaper Engine, app 431960) and
were created by **Z_DK**. Every item links to its Workshop entry in
`source.workshopUrl`, and its catalog key is the Workshop file id. The `author` field
is the Workshop creator (`Z_DK`), not the repository maintainer.

Rights to the wallpaper content remain with the original creator. If you are the
creator and want an item removed, open an issue titled `takedown: <workshop id>` or
contact the repository owner; the item, its preview and its release asset will be
removed.

The publisher tooling, index schema and documentation in this repository are MIT
licensed (same as Octocaris).
